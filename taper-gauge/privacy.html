Privacy Policy for TaperGauge

Last Updated: October 2026

TaperGauge ("the Application") is an offline machine shop utility created by KimRosil App Studio Company.

1. Zero Data Collection

TaperGauge does not track, collect, store, or transmit any user information, device identifiers, or machining logs. All calculations and configurations occur solely in local memory and private app sandbox storage.

2. No Network Access

The Application requires zero internet permissions (`android.permission.INTERNET` is not included in the application manifest). It functions completely offline in machine shop environments without cell or Wi-Fi reception.

3. Local Storage Only

Any custom taper presets or UI preferences saved by the user reside strictly on the local device storage. Uninstalling the application removes all associated local data.
