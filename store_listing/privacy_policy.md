# Privacy Policy for BrazeRing

**Effective Date:** October 27, 2026  
**KimRosil App Studio Company** (Developer: Eliakim Rosil)

BrazeRing is an offline-first utility application. All calculations, specifications, and job notes remain strictly on your local device.

### 1. Zero Data Collection
BrazeRing does not collect, transmit, store, or sell any personal data, location data, or device telemetry.

### 2. Zero External Network Requests
The application contains no third-party tracking SDKs, no advertising frameworks, and no analytics libraries. BrazeRing performs zero network connections and functions completely offline.

### 3. Local Storage Only
All saved braze job records reside within your local device's private SQLite database.

### 4. Permissions
• `android.permission.VIBRATE`: Provides tactile haptic feedback during interactive control taps.
• `android.permission.BIND_QUICK_SETTINGS_TILE`: Provides the Quick Settings tile in the system notification shade.
