# Privacy Policy for DuctFlow

**Last Updated:** October 2026

DuctFlow ("the Application") is an offline HVAC engineering calculation utility developed by KimRosil App Studio Company.

### 1. Zero Data Collection
DuctFlow does not track, collect, store, or transmit any user information, device identifiers, or airflow logs. All calculations and configurations occur solely in local memory and private app sandbox storage.

### 2. No Network Access
The Application requires zero internet permissions (`android.permission.INTERNET` is not requested or declared). All duct calculations run locally on your device hardware without external servers or cloud services.

### 3. Local Offline Storage
Saved duct runs and user theme preferences are stored exclusively on your device via SQLite. You can purge all saved data at any time via Settings > Clear Saved Ducts.

### 4. Third-Party Libraries
DuctFlow contains zero third-party software development kits (SDKs), analytics platforms, advertising frameworks, or telemetry libraries.

### 5. Contact
For questions or source code audits, visit [apps.kimrosil.com/duct-flow/](https://apps.kimrosil.com/duct-flow/).
