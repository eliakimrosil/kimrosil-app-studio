# Privacy Policy for RebarLap

**Last Updated:** October 2026

RebarLap ("the Application") is an offline structural calculation tool developed by KimRosil App Studio Company.

### 1. Zero Data Collection
RebarLap does not collect, record, track, or share any personal identity, construction plans, jobsite locations, or usage analytics. All structural computations are performed strictly in memory and local SQLite storage.

### 2. No Network Access
The Application requests zero network permissions (`android.permission.INTERNET` is not declared in the manifest). It functions completely offline in remote basements, trenches, and construction tunnels without internet reception.

### 3. Local Storage Only
Any saved splice configurations or UI preferences remain strictly within your local Android device sandbox. Uninstalling the application completely erases all stored data.
