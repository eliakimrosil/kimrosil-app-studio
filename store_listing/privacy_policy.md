# Privacy Policy for DoseCal

**Last Updated:** October 2026

DoseCal ("the Application") is an offline calculation utility developed by KimRosil App Studio Company.

### 1. Zero Data Collection
DoseCal does not collect, harvest, transmit, or share any personal identity, health information, patient logs, or device telemetry. All calculations and saved presets are processed purely locally in transient memory and a sandboxed on-device SQLite database.

### 2. No Network Access
The Application requests zero network permissions (`android.permission.INTERNET` is not included in the manifest). It operates completely isolated from the internet.

### 3. On-Device Storage
Any saved dose profiles, custom formulas, or UI preferences remain strictly on your local Android device storage within the app's secure private sandbox. Uninstalling the application completely erases all stored data.
