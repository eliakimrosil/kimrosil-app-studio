# Privacy Policy for WireAmp

**Last Updated:** October 2026

WireAmp ("the Application") is an offline electrical engineering calculation utility developed by KimRosil App Studio Company.

### 1. Zero Data Collection
WireAmp does not collect, record, track, or share any personal identity, electrical schematics, load logs, or usage analytics. All electrical calculations are performed purely in local memory and sandboxed SQLite storage.

### 2. No Network Access
The Application requests zero network permissions (`android.permission.INTERNET` is not included in the application manifest). It functions completely offline in metal breaker cabinets, electrical vaults, and basements without reception.

### 3. Local Storage Only
Any saved feeder runs, circuit profiles, or UI preferences remain strictly within your local Android device sandbox. Uninstalling the application completely erases all stored data.
