# CueScroll

Offline teleprompter for Android (Kotlin + XML, no third-party libraries).

- Smooth float-position auto-scroll driven by `Choreographer`
- Reading line, count-in, mirror mode, live WPM / remaining / elapsed telemetry
- Volume keys adjust speed; media and keyboard keys play/pause
- Private SQLite script library, Day / Night / Auto theme

Build: `gradle assembleDebug` (output in `build/outputs/`).
